# Node.js HTTP Server

A simple HTTP server built with Node.js using the built-in `http` and `fs` modules.

## Features

* Serves an HTML page using Node.js
* Serves CSS files
* Handles `/` and `/home` routes
* Handles 404 errors
* Uses Node.js built-in modules

## Project Structure

```text
Nodejs_Project/
├── server.js
├── frontend_folder/
│   ├── index.html
│   └── style.css
└── README.md
```

## How to Run

First, clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project folder:

```bash
cd Nodejs_Project
```

Run the server:

```bash
node server.js
```

Open your browser and visit:

```text
http://localhost:3001
```
